# SuperPaco

Proyecto público y abierto a contribuciones.

## Puesta en marcha

1. Clona el repositorio.
2. Copia `.env.example` a `.env` y rellena tus propias claves.
   **Nunca subas el archivo `.env` ni ninguna contraseña o clave al repositorio.**
